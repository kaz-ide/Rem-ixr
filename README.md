# Rem-ixr (Web Pad Sampler & Audio Remixer)

Webブラウザで動作するレスポンシブな8×5パッドサンプラー / リミキサーアプリです。
外部ライブラリへの過度な依存を避け、**Web Audio API** と **IndexedDB** を用いて高レスポンス・低遅延を実現しています。

---

## 主な機能・特徴

### 1. コントロールヘッダー（2段構成 & 初期化機能 & ZIPバックアップ）
- **1段目**: 
  - **左端**: ネオン発光のアプリ名（**Rem-ixr**）＋ バージョンバッジ（**Ver.1.01**）
  - **中央**: **プリセット選択コンボボックス**（10スロット保持）＆ **名前変更ボタン**
  - **右端**: **初期化ボタン**: タップ時に確認ダイアログ（モーダル）を表示後、現在開いているプリセットの全40パッドを初期状態（デフォルト音源セット）へ一括リセット。
- **2段目**:
  - **誤操作防止ロック（鍵アイコン）**: ロック時はパッド長押しによるファイル差し替えを無効化し、演奏中の誤爆を防止。
  - **ZIPバイナリバックアップ（書き出し / 復元）**:
    - **単一の .zip ファイル（`rem_ixr_backup_YYYYMMDD.zip`）** としてエクスポート。
    - ZIP内構成：`config.json`（設定・曲名メタデータ・アプリ識別子）＋ `audio/` フォルダ（音声ファイルのバイナリ実体をそのまま格納）。
    - Base64の肥大化を解消し、軽量スリムなバックアップを実現。
    - 書き出し・読み込み中は画面に **ローディング表示（プログレスバー＆スピナー）** を表示。
    - 従来の `.json` バックアップからの復元にも後方互換で対応。

### 2. 8 × 5（計40個）のパッドマトリクス
- **A〜H行 × 5列** の40パッド構成。
- **曲名ボタンのフォントサイズを30%拡大**: 視認性が向上し、演奏中でも曲名やアーティスト名が一目で分かります。
- **ネオン調カラー区分**:
  - **1列目（左端: マゼンタ/レッド）**: ドラム・リズムトラック（フェーダー連動、排他再生、ワンショット再生）
  - **2〜4列目（中央3列: シアン/ブルー）**: 効果音・ワンショット（常にフルボリューム、連打・多重再生可能）
  - **5列目（右端: ライム/グリーン）**: シンセ・ベーストラック（フェーダー連動、列内排他・クロスフェード）
- **各パッドのリピート（rpt）トグル**:
  - 全40パッドの右上端に `rpt ☑` / `rpt ☐` トグルボタンを装備（初期値OFF）。
  - **ON時**: `AudioBufferSourceNode.loop = true` となり、曲末尾に達してもシームレスに繰り返しループ再生。
  - **OFF時**: ワンショット再生（1回再生が終わると自動停止）。
  - 再生中にトグルを切り替えた場合も、即座に現在の再生へ反映。
  - 状態は10種類のプリセット、IndexedDB、ZIPバックアップ（`config.json`）に自動保存・復元。
- **パッドの曲名 & アーティスト名表示**:
  - ファイル選択時、**タグ情報（ID3v2, MP4/M4A, FLAC, WAV）を自動解析**。
  - **優先度**: ①タグのトラック名、下段にアーティスト名（ない場合は省略） / ②タグがない場合はファイル名（拡張子抜き）。
  - 長い曲名・アーティスト名はCSSで自動的に末尾「…」に省略。
- **操作**:
  - **タップ（クリック）**: 音声を再生 / 切り替え（再生中の同じパッドを押すと停止）。
  - **長押し（1秒）**: ロック解除時、パッドが白く光りバイブレーションが発動。指を離すと確認画面が開き、**3秒間無操作で自動的に音声ファイル選択画面が開きます**（待たずにボタンを押して即時選択することも可能。iPhone / iOS Safari 含む全ブラウザ完全対応。対応形式: `WAV`, `MP3`, `AAC (.m4a, .aac)`, `FLAC`）。

### 3. クロスフェーダー & 再生挙動（本家DJミキサー仕様）
- **クロスフェーダー位置（0.0 〜 0.5 〜 1.0）**:
  - **左端（0.0）**: 赤列 100%（MAX）、緑列 0%（ミュート）
  - **中央（0.5）**: 赤列 100% ＋ 緑列 100%（両方MAXで同時フル再生ブレンド）
  - **右端（1.0）**: 赤列 0%（ミュート）、緑列 100%（MAX）
- **DJクロスフェーダーカーブ**:
  - 0.0〜0.5: 赤列は100%を維持し、緑列が0%から100%へスムーズに増加
  - 0.5〜1.0: 緑列は100%を維持し、赤列が100%から0%へスムーズに減少
- **赤列と緑列の同時再生（ブレンド再生）**:
  - 赤列と緑列の排他制限を撤廃。両方の曲を同時に流し、クロスフェーダーで自由自在にブレンドできます。
- **中央スナップ**:
  - 中央付近（±2%以内）で自動的に `0.5` に吸着し、両トラックが100%で同時ブレンド再生されます。
- **列内クロスフェード**:
  - 同じ列内（赤列同士、緑列同士）で別の行を押した際は、旧曲が0.5秒でフェードアウトし、新曲へスムーズに切り替わります。
- **スライダーの太さを2倍（24px）に拡大**: タッチやマウスで操作しやすい重厚感と視認性を備えたカスタムノブ。

### 4. 即時演奏できるビルトイン音源
- 外部音声ファイルが手元になくても、アプリ起動時に Web Audio API による合成音源（ドラムビート、シンセベース、クラップ、レーザー、コードスタブ、ライザー等）が自動セットされるため、開いた瞬間からリミックス演奏を楽しめます。

### 5. レスポンシブ & モバイル最適化
- **縦画面（ポートレート）**: スマホ向けに全パッドが画面内に収まり、タップしやすい最適レイアウト。
- **横画面（ランドスケープ）**: ワイド画面をフル活用した快適な操作性。
- **スマホ横画面（低画面高）救済モード**: iPhoneなどのスマートフォンを横画面にした際（画面高が小さい環境）、自動的に「枠と曲名のみ」の簡易レイアウトへ移行。アーティスト名や装飾波形を非表示にし、上下ヘッダー・フッターもスリム化することで、極小の高さでも曲名がはっきりと読め、演奏可能になります。
- **iOS/Safari 対応**: 初回タッチ時の `AudioContext.resume()` 自動アンロック、ダブルタップ遅延を防止する `touch-action: manipulation` を採用。
- **バックグラウンド再生キープアライブ**: iOS / Safari 等で画面ロックや他アプリへ移動しても音が消えず演奏が継続（ブラウザタブを閉じると確実に完全解除されます）。

## 起動方法

### 方法1: 直接ブラウザで開く
フォルダ内の `launch.bat` をダブルクリックするか、`index.html` を任意のモダンブラウザ（Google Chrome, Microsoft Edge, Safari, Firefox 等）で直接開いてください。

### 方法2: ローカルHTTPサーバーで起動する場合
任意のHTTPサーバーでフォルダを配信してアクセスしてください。
